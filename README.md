# Can my small pet eat this? An open table of 306 food answers

A plain table of which everyday foods are fine, fine now and then, or not for nine small pets: rats, rabbits, guinea pigs, hamsters, mice, gerbils, chinchillas, degus and ferrets.

Each row gives the animal, the food, a short answer (`yes`, `sometimes` or `no`), how often (`daily`, `weekly`, `occasional` or `never`), a one-line answer with the amount, and a link to the full page with the reasons and how to serve it.
